_This page discusses node forging (grouping), an upcoming feature that may change before final release_

# Mining

Mining is essential for obtaining valuable minerals, which allow you to do multiple things:

*   Create fishing rods.
*   Craft pickaxes to mine minerals.
*   Build oil drills to extract oil.
*   Use minerals to expand your land.
*   Use minerals to construct or upgrade buildings.
*   Use minerals to acquire SFTs from the blacksmith.
*   Craft shovels and drills to find treasures on the beach.
*   Complete deliveries.

In short, we need to mine (or buy minerals from the market) to progress in the land or simply enjoy the various activities mentioned above.

The basic flow of mining is: chop trees → use the wood for pickaxes to get stone → make stone pickaxes to get iron → make iron pickaxes to get gold → make gold pickaxes to get Crimstone or Sunstone.

## Stone

To obtain **stone**, we need to craft a pickaxe, which will allow us to mine the **Stone Rock**.

![](/pickaxe.png)

Cost and restock of pickaxes

As we progress through the game, we’ll be able to obtain **Sunstone**, which can be used to unlock additional **Stone Rock** nodes. The initial cost for the first Stone Rock node is **4 Sunstone**, and it increases by **+3 Sunstone** for each subsequent node.

![](/stone_rock.png)

Soon, it will be possible to **group Stone Rocks together** to obtain more stone and make mining more convenient.

## Mining skills

![](/mining_skills.png)

Mining skills

Having a **mining skill tree** allows us to create a strategy to optimize it.

Here are several examples:

*   **Stone Specialist:** **Rock’N’Roll, Speed Miner, Forge-Ward Profits, Frugal Miner, Rocky Favor**
*   **Iron Specialist:** **Rock’N’Roll, Iron Bumpkin, Forge-Ward Profits, Frugal Miner, Iron Hustle, Ferrous Favor**
*   **Gold Specialist:** You can use the Stone or Iron specialist setup (or even combine both if you want to be a complete player) and add **Golden Touch, Midas Sprint, Midas Rush**.
*   **Crimstone Specialist:** You can use the Stone or Iron specialist setup (or combine both if you want to be a complete player) and add **Fire Kissed, Fireside Alchemist**.
