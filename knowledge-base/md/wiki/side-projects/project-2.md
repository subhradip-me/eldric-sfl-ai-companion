## Yakkamon

**Yakkamon** (known as Project II during development) is a monster-collecting tactical battler game set in the FLOWER ecosystem. It is a standalone project, not a mini-game, and is being developed alongside _Sunflower Land_. The game is confirmed to be a **creature collector** with roguelike elements, real-time speed-based combat, farming mechanics, and a shared economy with _Sunflower Land_ via the FLOWER token.

Official website: [https://yakkamon.com](https://yakkamon.com)

> **Original announcement (August 2021–2025 context):**  
> _Project II is confirmed to be a monster-collecting tactical battler game. Other than using the FLOWER token to buy and sell resources, no other connections to Sunflower Land have been confirmed yet._  
> — Medium: _Sunflower Report – The Road to 2026_

### 🔧 Development Timeline (2026)

#### January 2026

*   **2026-01-06** – Core combat prototype begins internal testing. The team is satisfied with the combat model and begins prototyping meta-game systems around it. A future stream or GIF showing progress is possible.
*   **2026-01-20** – Beta is scheduled for **Q3 2026**. The game is described as a “rethink of web3 gaming”: a creature catcher/trading game with a shared economy with _Sunflower Land_. It is not a farming game and aims to attract new audiences (e.g., no Bumpkin battles in SFL).

#### February 2026

*   **2026-02-10** – GitHub development progresses. After core mechanics are locked, beta is expected in **July/August 2026**.
*   **2026-02-13** – Spencer moves to full-time P2 development. Genre confirmed as **creature collector**. Influences include _Temtem_ and _Slay the Spire_. The game will be web-based, mobile-friendly, with menu-oriented combat (not MMO-style). FLOWER token will be incorporated with its own economy. Possible tournament systems with entry fees are discussed.
*   **2026-02-19** – Vertical slice spec document completed. Combat is **not turn-based** but **real-time speed-based** (similar to _Final Fantasy VII_). Key features:
    *   Runs (roguelike style)
    *   Taming creatures
    *   Farming with creatures
    *   PvP
    *   Economic design: creatures require resources for healing, feeding, training
    *   Resources burned in P2 will also burn FLOWER from _Sunflower Land_
    *   Breeding mini-game planned with stat genetics
    *   Player-vs-player combat will help counteract inflation
*   **2026-02-27** – First sneak peek. The game features monster battling, exploration, and farming elements. Roguelike exploration approach with runs, battles, resource gathering. Same FLOWER token across both games. A **centralized marketplace** is shared between games. Beta target remains Q3 2026. A public prototype may be released early for feedback.

#### March 2026

*   **2026-03-05** – Spencer works exclusively on P2. A breakthrough in game look and UI is achieved with Adam. A tutorial run is shown with nodes for battles and other activities. The game is built with **Unity** (different from _Sunflower Land_’s React). A “vertical slice” (full run of the game) is being built for feedback.
*   **2026-03-13** – Core mechanics detailed:
    *   **Roguelike exploring and taming**
    *   **3 core aspects**: farming, battling, roguelike adventure
    *   **3v3 battles** with type advantages (e.g., water cancels electricity)
    *   Farm with monsters – catch monsters and put them to work on fields
    *   Gather resources to feed monsters and prepare for battle
    *   Monsters have types affecting both battles and farming (e.g., desert monsters for certain plots)
    *   **Launch plan**:
        *   Beta launch: closed – top _Sunflower Land_ players first
        *   Next round: competition inside _Sunflower Land_
        *   Then restricted to ~10,000 players for load testing
        *   Will use FLOWER and have a marketplace for trading creatures/resources

#### April 2026

*   **2026-04-02** – **Public prototype demo released** at [project-ii.sunflower-land.com](https://project-ii.sunflower-land.com/).
    *   Only one creature (**Grassling**) is initially available.
    *   Players can capture creatures and attempt to reach **Firebug Level 2** (boss).
    *   Not playable on mobile at this time.
    *   Feedback button is available on the farm screen under the shop icon.
    *   **No plans** to use pets or buds from _Sunflower Land_ – the game will have its own original creatures.

### 🎮 Confirmed Game Features (as of April 2026)

| Category | Details |
| --- | --- |
| **Genre** | Monster collector, roguelike, tactical battler |

### 🌸 FLOWER Token Usage in Project II

As originally announced, FLOWER remains the native token for:

*   NFT drops
*   Gameplay perks
*   Exclusive content

Additionally, based on 2026 updates:

*   FLOWER will be used for healing, feeding, training creatures
*   Burning resources in P2 also burns FLOWER from _Sunflower Land_, linking the economies
*   A shared marketplace will allow trading creatures and resources using FLOWER

* * *

### 🔗 Relationship to Sunflower Land

*   **Sunflower Land remains the primary focus** of the team and the primary FLOWER generation method.
*   Project II is a **separate game** with its own creatures, systems, and economy, but shares the FLOWER token.
*   There is **no cross-use** of Sunflower Land pets or buds in Project II.
*   Top Sunflower Land players will receive priority access to the closed beta.

* * *

### 🛡️ Development Philosophy

*   No ICO, no direct sale of FLOWER.
*   Built in public from scratch, with community feedback from day one.
*   Open-source principles, sustainable economies, community-first design.
